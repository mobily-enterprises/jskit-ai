# Changelog

## Unreleased

- `unsupportedClaims({ model, reply, record, transcript })` takes the reply's `transcript`, optionally. Given it, a claim the check names is supported when it has five words or more, is not in the first person singular, and one of the reply's own tool results holds it word for word, case, punctuation and spacing aside: the reply reported it from a record it read, it did not claim it. `toolRecord` shows the checker only the first 240 characters of each result, so CompAS's assistant, which read an email saying "We forwarded this to OCEAN EMERALD at 19:03" and repeated it, was sent back for claiming a forward it never made (jskit-ai#495). "I've sent the email", "We've forwarded it" and a claim no result holds are still sent back. Without `transcript`, as before, every claim the check names stands; the result is still at most five claims.
- `estimateTokens`, which the history window (`withinBudget`) and a long turn's trimming (`trimOldResults`) both count with, counts a file or picture part by its size instead of by the JSON that writes out its bytes, several characters a byte: a picture costs 1,000 tokens, and a file a token per four bytes, or 1,000 when its size is unknown (a link), whether its data is a Buffer, a typed array, base64 text or a data URL. An attached file of about 80 KB used to outweigh a 128k-token model's whole history, so every earlier message was dropped, and an attached picture made a turn leave out its older tool results.
